# เก็บข้อมูลเพื่อวัดและปรับระบบ (ไม่ต้องเทรนโมเดล)

ระบบเป็น keyword + FAQ ไม่มีการเทรน ข้อมูลใช้ 3 อย่าง: วัดความแม่น, หา keyword ที่ขาด, เขียนคำตอบ FAQ

## ขั้นตอน
1. คัดลอกข้อความลูกค้าจริง (Messenger/LINE) ใส่ไฟล์ CSV ตามแบบ `templates/labeled_template.csv`
   คอลัมน์: `text, true_intent, staff_reply, needs_human`
2. ลบข้อมูลส่วนตัว:
   `PYTHONPATH=. python3 -m phase8.tools.anonymize data/raw.csv data/clean.csv --column text --column staff_reply`
   แล้ว **เปิดอ่านไฟล์ clean.csv เอง** ชื่อคนและที่อยู่ไม่ถูกตรวจจับ
3. ให้คนติดป้าย `true_intent` (I01-I18 หรือ I99 = ทักทาย/ไม่ชัด) ให้คนที่รู้งานจริงเป็นคนติด
4. วัดผล:
   `PYTHONPATH=. python3 -m phase8.tools.evaluate data/clean.csv --misses data/misses.csv`
5. ดู `misses.csv` → เพิ่ม keyword ใน `phase8/classifier_ext.py` → วัดใหม่ → ทำซ้ำ

## กติกา
- เก็บไฟล์ไว้ใน `assist/data/` (ถูก .gitignore กันไว้แล้ว) ห้าม commit ข้อมูลลูกค้า
- ลบข้อมูลส่วนตัวก่อนส่งให้ใครดู รวมถึงแชทกลุ่มทีม
- หมวดเสี่ยง (I03 ฮาลาล/สารก่อภูมิแพ้/ความปลอดภัยสินค้า, I07 ขายส่ง/ส่งออก, I14 ร้องเรียนคุณภาพ) เก็บให้ครบทุกเคสที่มี
- ตัวเลขความแม่นจะเชื่อถือได้เมื่อมีข้อความต่อหมวดมากพอ (เริ่มที่ ~30 ต่อหมวดที่พบบ่อย)

## ดูผลและ export ผ่านเบราว์เซอร์ (ไม่ต้องมีหน้าเว็บ)
1. ตั้งตัวแปร `ASSIST_EXPORT_PASSWORD` (รหัสยาวๆ สุ่มเอง) บนเซิร์ฟเวอร์ แล้วรีสตาร์ท
2. เปิดในเบราว์เซอร์ (ต้องเป็น https):
   - `https://<โดเมน>/export/summary` สรุปจำนวนแยกหมวดและวัน
   - `https://<โดเมน>/export/cases.csv` ไฟล์เคส (ไม่มีข้อความลูกค้า)
   - `https://<โดเมน>/export/collected.csv` ข้อความคำถามที่ลบข้อมูลส่วนตัวแล้ว (เมื่อเปิด `ASSIST_STORE_TEXT=1`)
3. เบราว์เซอร์จะขอล็อกอิน: ชื่อผู้ใช้ใส่อะไรก็ได้ รหัสผ่านคือค่าที่ตั้งไว้
ไม่ตั้งรหัสผ่าน = ปิดฟีเจอร์นี้ (ตอบ 404)

## รันบน Windows แบบไม่ต้องพิมพ์ยาว
1. คัดลอก `local.env.example` เป็น `local.env` แล้วแก้ค่า (ไม่มีช่องว่างรอบเครื่องหมาย =)
2. ดับเบิลคลิก `run_local.bat` เพื่อเปิดเซิร์ฟเวอร์ (เปิดหน้าต่างค้างไว้)
3. ดับเบิลคลิก `start_tunnel.bat` เพื่อเปิด tunnel (ต้องติดตั้ง cloudflared) แล้วคัดลอก URL ที่ได้ไปใส่ Webhook URL ของ LINE
4. ดูผล: `http://localhost:8080/export`
