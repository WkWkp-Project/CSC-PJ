# CSC-PJ Dashboard — สรุปวิเคราะห์แชทลูกค้า Tulip

หน้า dashboard สรุปผลวิเคราะห์แชทลูกค้า Tulip จาก **3 แหล่งข้อมูล วิเคราะห์แยกกัน (ไม่รวมกัน)**
รองรับ 3 ภาษา (ไทย / English / 日本語) + โหมดมืด

> 🌐 **เปิดดูสด:** https://wkwkp-project.github.io/CSC-PJ/
> 📄 branch นี้มีเฉพาะหน้า dashboard (`index.html`) · โค้ด/สคริปต์อยู่ที่ branch `claude/csc-pj-connect-3d20y0`

## 3 แหล่งข้อมูล

| แหล่ง | บทบาท | ปริมาณ | ช่วงเวลา |
| --- | --- | --- | --- |
| **Messenger** | ลูกค้า → เพจ | 383 บทสนทนา | 365 วัน |
| **LINE · แบรนด์** (Tulip Sino × Wkwk) | ประสานงานแบรนด์/แคมเปญ | 1,660 ข้อความ | ~3 ปี |
| **LINE · CS** (Asian Bridge × Wkwk) | แก้ปัญหาลูกค้าจริง | 1,227 ข้อความ | ~1 ปี |

## ผลสรุปหลัก

**① Messenger — ลูกค้าทักมาเรื่องอะไร**
- 🛒 ก่อนการขาย (สนใจสินค้า): **72.6%** (278 บทสนทนา)
- 📦 หลังการขาย (บัตร/พัสดุ/เคลม): 16.7% (64)
- ❔ อื่นๆ: 10.7% (41)

**② LINE แบรนด์** — คุยคอนเทนต์/แคมเปญเป็นหลัก · เคลมลูกค้าแค่ **5 ครั้งใน 3 ปี**

**③ LINE CS — เวลา CS รอ Wakuwaku ตอบ** (241 คู่ถาม-ตอบ)
- เวลากลาง **9 นาที** · ตอบใน 1 ชม. **73.9%** · เกิน 24 ชม. **7.9%** (~19 เคส)

## ข้อค้นพบสำคัญ

1. **สายแบรนด์ vs สาย CS แยกกันชัดจริง** — ยืนยันด้วยข้อมูลจริง
2. **คอขวดไม่ใช่ความเร็วทีม** — Wakuwaku ตอบเร็วมาก ปัญหาคือหาง 7.9% ที่รอแบรนด์เกิน 24 ชม.
3. **"ของรางวัล/แลกของ" คือจุดร่วม** — เด่นทั้ง Messenger และ LINE CS → ควรทำคลังคำตอบมาตรฐานก่อน
