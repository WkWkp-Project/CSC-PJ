## ข้อค้นพบสำคัญ

1. **~73% ของแชทเป็นคำถามซ้ำที่ AI ตอบได้** (ราคา ช่องทางซื้อ ข้อมูลสินค้า ขายส่ง)
   → ยืนยันคุณค่าข้อ 1 ใน README: "ตอบคำถามซ้ำๆ ให้อัตโนมัติ"
2. **"บัตร/ของรางวัล" 12.3% คือจุดเจ็บอันดับ 1 ที่ต้องพึ่งคน**
   → ตรงกับที่ README วิเคราะห์ไว้ (เคสรอแบรนด์/รอดำเนินการ ลากยาว ลูกค้าตามซ้ำ)
3. **ลูกค้าจำนวนมากทักด้วยประโยคสั้น** ("สวัสดีค่ะ", "สอบถามค่ะ") ก่อนเข้าเรื่องจริง
   → AI ต้องถามต่อเพื่อดึง intent (ออกแบบไว้ใน flow ข้อ 3 ของ README แล้ว)

## ⚠️ ข้อจำกัดของตัวเลขชุดนี้ (ต้องบอกตามจริง)

ผลนี้มาจาก **rule-based (จับคีย์เวิร์ด)** ซึ่งมีความคลาดเคลื่อน:

- **หมวด "สอบถามทั่วไป/ทักทาย" 36% สูงเกินจริง** — จับคำว่า "ครับ/ค่ะ/สวัสดี"
  ซึ่งเจอเกือบทุกแชท ทำให้บางเคสที่จริงเป็น *ปัญหาบัตร/รหัส* (ต้องพึ่งคน) ถูกนับรวมเข้ามา
  → **ตัวเลข "AI ตอบได้ 73%" จึงน่าจะสูงเกินจริง ค่าจริงต่ำกว่านี้**
- มีเคส **สแปม/ฟิชชิ่ง** ปนในข้อมูล (ข้อความหลอกว่าเพจถูกบล็อก) — ควรกรองออก
- บาง "อื่นๆ" จริงๆ เป็นคำถามที่ AI ตอบได้ (เช่น ถามช่องทางจำหน่าย)

**คำแนะนำ:** รันซ้ำด้วย **โหมด AI** (`--mode ai`) เพื่อจัดหมวดแม่นขึ้น
แล้วใช้ตัวเลขชุดนั้นเป็นฐานอ้างอิงในการนำเสนอ/ตั้งราคา

## ข้อเสนอถัดไป (อิงผลจริง)

1. **เฟส 1 — Automate 3 หมวดใหญ่ที่ชัวร์:** ถามราคา, ช่องทางซื้อ, ขายส่ง
   (รวม ~33% ของแชท และเป็นคำถามที่คำตอบตายตัว)
2. **เฟส 1 — คลังความรู้:** รวบรวมคำตอบมาตรฐาน (ราคา/ช่องทาง/สเปคสินค้า) เข้าคลัง FAQ
3. **เฟส 2 — ระบบจัดคิว "บัตร/ของรางวัล":** ไม่ให้เคสหาย + เตือนเมื่อค้างนาน
   (จุดเจ็บอันดับ 1 ที่ต้องพึ่งคน)
4. **ก่อนตั้งราคา:** รันโหมด AI เพื่อได้ % ที่แม่นยำ แล้วค่อยประเมินภาระงานจริง
