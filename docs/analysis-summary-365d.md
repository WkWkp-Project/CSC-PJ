## ข้อค้นพบจากการวิเคราะห์

1. **ลูกค้าส่วนใหญ่ (~73%) ทักมาช่วง "ก่อนการขาย"** — สนใจราคา ช่องทางซื้อ ข้อมูลสินค้า
   → เพจทำหน้าที่เป็น "หน้าร้าน/จุดให้ข้อมูล" เป็นหลัก
2. **คำถามซ้ำเยอะมาก** — "ถามราคา" (13.6%) + "ช่องทางซื้อ" (8.4%) เป็นคำถามที่คำตอบตายตัว
   ตอบเหมือนเดิมแทบทุกครั้ง
3. **ความสนใจแบบขายส่ง/ตัวแทนสูง** — "ขายส่ง/ราคาส่ง" 11% (ลูกค้าอยากซื้อจำนวนมาก/เปิดร้าน)
   → เป็นโอกาสทางธุรกิจ ควรมีข้อมูล/ขั้นตอนรองรับให้ชัด
4. **งานบริการหลังการขายกระจุกที่ "บัตร/ของรางวัล" (12.3%)** — เป็นภาระงานหนักสุดของทีม
   (เคสรอดำเนินการ/รอของรางวัล ลากยาว ลูกค้าตามซ้ำ) ตรงกับจุดเจ็บใน README
5. **ลูกค้ามักทักด้วยประโยคสั้น** ("สวัสดีค่ะ", "สอบถามค่ะ") ก่อนเข้าเรื่องจริง
   → ต้องมีคนถามต่อเพื่อดึงเรื่องที่แท้จริง

## ⚠️ ข้อจำกัดของตัวเลขชุดนี้ (ต้องบอกตามจริง)

ผลนี้มาจาก **rule-based (จับคีย์เวิร์ด)** ซึ่งมีความคลาดเคลื่อน:

- **หมวด "สอบถามทั่วไป/ทักทาย" 36% สูงเกินจริง** — จับคำว่า "ครับ/ค่ะ/สวัสดี"
  ซึ่งเจอเกือบทุกแชท ทำให้หลายเคสที่จริงมีเรื่องเฉพาะถูกเหมารวมเข้ามา
- มีเคส **สแปม/ฟิชชิ่ง** ปนในข้อมูล (ข้อความหลอกว่าเพจถูกบล็อก) — ควรกรองออก
- บาง "อื่นๆ" จริงๆ เป็นคำถามที่จัดเข้าหมวดได้ (เช่น ถามช่องทางจำหน่าย)

**สรุป:** ตัวเลขระดับ "ภาพรวม/สัดส่วนคร่าวๆ" ใช้ได้ แต่ถ้าต้องการความแม่นระดับตัดสินใจ
ควรทบทวนคีย์เวิร์ด หรือจัดหมวดซ้ำอีกรอบ
