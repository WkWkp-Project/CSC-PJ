## ข้อค้นพบสำคัญ

1. **การสมัคร workshop เป็นก้อนใหญ่ที่ซ่อนอยู่ (~9 ราย, ~23%)**
   ลูกค้าทักมาลงชื่อร่วมกิจกรรม "ลงมือทำขนมกับเชฟโจ" — เป็นงาน **operational** (เก็บชื่อ/เบอร์/ยืนยันสิทธิ์)
   ไม่ใช่คำถามขาย → ควรมีฟอร์ม/flow ลงทะเบียนแยก

2. **Lead ขายส่งรั่วได้ (~9 ราย ที่จบด้วย "ส่งต่อเซลล์")**
   หลายเคสจบแบบส่งฟอร์ม/ส่งต่อเซลล์ แล้ว **ลูกค้าเงียบ** (C28) หรือ **เซลล์โทรไม่ติด** (C36)
   → มีความเสี่ยงเสียโอกาสการขาย ควรมีระบบติดตาม lead

3. **ตอบช้า/ข้ามวัน ~41% คือปัญหาจริง**
   หลายเคสมี auto-response ทักแรก แต่คนตามมาตอบช้า (ข้ามวัน) — ลูกค้าบางรายทวงหรือหายไป

4. **คำถาม "เจ/vegan" ซ้ำบ่อย (~5 ราย)**
   ตอบเหมือนกันทุกครั้ง (100% เจ/plant-based/keto) → คำตอบตายตัว เข้าคลัง FAQ ได้ทันที

5. **ของขาดตลาด + ลิงก์ marketplace เสีย (~3 ราย)**
   Matcha/Mirror Glaze ขาดซ้ำ, ลิงก์ Lazada ใช้ไม่ได้ → กระทบประสบการณ์ซื้อ

6. **เคสร้องเรียนคุณภาพเชิงลึก 1 ราย (C22)**
   ลูกค้าผู้เชี่ยวชาญ ร้องเรียนคุณภาพผงโกโก้ 32% ลดลง + ถามเชิงเทคนิค (ไขมันโกโก้/ฟลาโวนอยด์)
   คุยยาวข้ามหลายเดือน สุดท้ายยังค้าง — เป็นเคสที่ AI ตอบเองไม่ได้ ต้องส่งแบรนด์

## เทียบกับชุดอื่น (ยืนยันซึ่งกันและกัน)

- "ขายส่ง + ข้อมูลสินค้า + ช่องทางซื้อ" เด่นทั้งชุดนี้และ API 383 → คำถามก่อนการขายคือส่วนใหญ่
- "บัตร/ของรางวัล" โผล่ทั้ง Messenger และ LINE CS → งานหลังการขายที่ต้องพึ่งคน
- ชุดนี้เพิ่มภาพ **"workshop registration"** และ **"lead ขายส่งรั่ว"** ที่ 2 ชุดแรกไม่เด่น

## ข้อจำกัด
- 39 รายเป็นชุด capture มือ (อาจถูกเลือกมาบางส่วน) — สัดส่วนใช้ดูเชิงคุณภาพ ไม่ใช่สถิติประชากร
- การตัดสิน "ตอบจบ/ค้าง" อ่านจากภาพ ณ เวลา capture — เคสที่ตามต่อภายหลังอาจเปลี่ยน
